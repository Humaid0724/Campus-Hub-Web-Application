About Campus Hub

Built by Students, for Students

Our Story

Campus Hub was born from a simple yet powerful idea: academic life shouldn't be scattered across a dozen different platforms. As students at Heriot-Watt University Dubai, we experienced firsthand the frustration of missing important notices, losing track of assignment deadlines, and struggling to find lost items on campus.

What started as a coursework project evolved into a comprehensive solution that addresses real campus challenges. We asked ourselves: "What if everything a student needs was in one place?" This question drove us to create a platform that truly understands student needs.

Over weeks of planning, designing, and coding, we transformed our vision into reality. Campus Hub now serves as the digital heartbeat of student life at HWUD, connecting students to opportunities, resources, and each other.

What We've Built

Campus Hub delivers over six core functionalities that streamline campus life:

  • Event Management: Post events, RSVP, and manage your personal calendar
  • Academic Calendar: Track courses, deadlines, and important dates
  • Task Manager: Organize assignments with priority levels and due dates
  • Lost & Found: Report lost items and help return found belongings
  • Resource Exchange: Share study materials and borrow from peers
  • Campus Notices: Stay updated with official announcements

Each feature includes full CRUD operations (Create, Read, Update, Delete) powered by a robust MySQL database. We implemented role-based access control so students and admins have appropriate permissions.

Technology Stack

We leveraged the full course curriculum to build Campus Hub:

Frontend

HTML5 · CSS3 · JavaScript · jQuery

Backend

Node.js · Express.js

Database

MySQL · JSON data transfer

Storage

Web Storage for local data persistence

Our architecture follows client-server principles with RESTful API design. We prioritized security, implementing bcrypt for password hashing and session management for user authentication.

Looking Ahead

While Campus Hub is currently a proof-of-concept, the foundation is solid for future expansion. We envision adding real-time chat, push notifications, mobile app integration, and AI-powered study recommendations.

This project represents more than just coursework—it's a glimpse into how technology can transform the student experience. We hope it inspires future cohorts to build tools that make campus life better for everyone.
